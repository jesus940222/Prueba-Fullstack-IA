# Fase 6: IA, chat, RAG, métricas y alertas

Implementa docs/07 y contratos correspondientes; lee reglas de seguridad antes del grafo.

- FastAPI, SQLAlchemy/Alembic y DB propia. Adaptador LangGraph con checkpoints sin secretos.
- Modelo OpenAI configurable que soporte herramientas/salidas estructuradas; verificar docs oficiales.
- text-embedding-3-large y Qdrant con dimensiones/filtros/versiones explícitos.
- Pipeline idempotente de documentos knowledge, baja lógica y validación de vigencia/audiencia.
- System/few-shot versionados, fuentes visibles y respuesta sin evidencia honesta.
- Catálogo de tools tipadas en código; delegación de sesión/permiso en cada llamada.
- No SQL/HTTP libre, admin de accesos o confirmación autónoma.
- Chat prepara transferencia, tarjeta backend y confirmación frontend -> Cuentas.
- Pausa/reanudación no repite efectos; reconexión de stream no inicia otro run.
- Propiedad de conversaciones/mensajes/ejecuciones y borrado lógico.
- Streaming autenticado sin tokens de URL, cancelación y errores recuperables.
- Medición agregada de llamadas/retries/tokens/caché y coste versionado; incomplete distinto de cero.
- Embeddings consulta vs indexación separados.
- Frontend muestra métricas propias; admin consulta métricas ajenas sin acceso al chat.
- Alertas de coste con dedupe/cooldown, solo admins, UI/email local y auditoría.
- Presupuestos duros con control de concurrencia/estimación y límites de pasos/tokens/tiempo.
- LangSmith off por defecto; exportación redactada y fallos sin romper aplicación.
- Evaluación versionada y script reproducible con reporte real.

Gate:
RAG cita y no inventa; ofertas vigentes por API; ambigüedad pide datos.
Cuenta ajena/rol sin permiso/documento malicioso no amplía acceso.
No transferencia sin botón, con sesión revocada o propuesta vencida.
Timeout, 429, proveedor caído, cancelación y reintentos sin efectos duplicados.
Tokens/coste de varias llamadas, uso incompleto y alertas solo admin probados.
Capturador de trazas verifica ausencia de secretos incluso subtools.
Unitarios/integración/e2e y cobertura >=70% del servicio.
Eval real opt-in con credenciales; no inventar latencia/costes si se usó proveedor simulado.
